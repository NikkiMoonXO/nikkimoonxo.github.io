# Nikki Moon website

This site uses plain HTML, CSS and JavaScript. No installation or build step is needed.

## Publish

Open repository Settings → Pages. Set Source to **Deploy from a branch**, choose **main** and **/ (root)**, then Save.

## Profile links

Add confirmed Instagram, TikTok, X and exclusive-content URLs to the `links` object at the top of `app.js`. Empty entries display as unavailable.

## Photos

The starter gallery uses three supplied Nikki images, optimised for the web. Gallery buttons open full images and work with a keyboard. Replace images in `assets/` and update their alt descriptions in `index.html` when changing photos.

## Instagram automation

This first version is a curated gallery. It does **not** automatically retrieve Instagram posts or videos. A later integration needs confirmed profile details and supported Instagram account/API access. Do not place access tokens in public source files.

The Exclusive section currently has no outgoing destination. Add the confirmed platform URL before promoting it. The public site contains no explicit imagery.
